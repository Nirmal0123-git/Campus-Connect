# 🎓 Campus Connect – Career & IT Project Showcase

**Campus Connect** is a responsive web application designed for students and professionals to create career profiles, submit their professional details, and explore innovative IT projects developed using modern technologies.

The application provides a user-friendly interface with a career application form, profile management functionality, and an IT project showcase featuring 10 different technology-based projects.

---

## 🚀 Features

### 🏠 1. Home Page
- Attractive and modern landing page.
- College branding and navigation bar.
- Career opportunity introduction section.
- Apply Now button for easy navigation to the career application form.

### 📝 2. Career Application
- User-friendly career application form.
- Collects the following details:
  - Full Name
  - Email Address
  - Professional Role
  - Password
- Input validation to ensure correct information.
- Custom validation error popup.
- Success message after successful submission.

### 👤 3. Profile Management
- Automatically generates a profile card after successful submission.
- Displays user information.
- Shows the user's initials as a profile avatar.
- Edit functionality to update submitted information.
- Delete functionality to remove the profile.
- Password is displayed in masked form.

### 💻 4. IT Project Showcase
Displays 10 innovative IT projects:

1. AI Career Assistant
2. Smart Hospital Management
3. IoT Smart Home
4. Cloud File Management
5. Cybersecurity Threat Monitor
6. Blockchain Certificate Verification
7. Student Performance Analytics
8. Online Learning Platform
9. Expense Management System
10. DevOps CI/CD Dashboard

Each project includes:
- Project image
- Project title
- Project description
- Technologies used

### 📞 5. Contact Section
- College information.
- Location details.
- Contact number.
- Copyright information.

### 📱 6. Responsive Design
- Mobile-friendly interface.
- Tablet and desktop compatibility.
- Responsive project card layouts.
- Smooth scrolling and interactive hover effects.

## ⚙️ Installation & Setup

Follow these steps to run the project on your local machine.

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Campus-Connect.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Campus-Connect
```

### Step 3: Open the Project

Open the project folder in Visual Studio Code.

### Step 4: Install Live Server

Install the **Live Server** extension in VS Code.

### Step 5: Run the Application

1. Open `index.html`.
2. Right-click anywhere in the editor.
3. Select **Open with Live Server**.

Alternatively, use the configured Live Server port:

```text
http://127.0.0.1:5501
```

The application will open in your default browser.

## 🔍 Form Validation

The career application form includes the following validation rules:

| Field | Validation |
|---|---|
| Name | Only letters and spaces; 2–50 characters |
| Email | Must follow a valid email format |
| Role | Required; minimum 2 characters |
| Password | Minimum 8 characters, including letters and numbers |

If invalid information is entered, an error popup displays the appropriate message.

## ⚠️ Important Note

This version is a frontend demonstration. Form submissions and profile information are managed using React state and are not permanently stored in a database.

The password field is included for demonstration purposes only. A production application should use secure authentication, password hashing, and backend validation. Never store plaintext passwords.
